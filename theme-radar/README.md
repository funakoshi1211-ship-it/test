# テーマ株レーダー

日本株の「テーマ株の初動」を毎日自動で見つけて、**強いシグナルのときだけ**メールで知らせる仕組みです。
2026年10月6日のサイバーセキュリティ株のように、同じテーマの銘柄がまとまって動き出す動きを、できるだけ早く捉えることを狙っています。

- **GAS（Googleスプレッドシート）**：毎日16時台・17時台に、24テーマ・約190銘柄の株価を自動で取得し、テーマごとの「熱量」と段階を判定する
- **Claude の定期実行**：平日18:47に結果を読み、ニュースで裏付けを取り、監視外の新しいテーマも探して、強いシグナルのときだけ Gmail で知らせる（指示文：[docs/ROUTINE.md](docs/ROUTINE.md)）

費用はかかりません。

## 何を見ているか

テーマ株の相場は、たいてい次の順に進みます。1銘柄ずつではなく、**テーマの銘柄がまとまって動き出したか**を毎日数字にして、段階の変わり目を知らせます。

| 段階 | 判定の中身 | 行動の目安 |
|---|---|---|
| 予兆 | 直近5日で2銘柄が急騰（+8%以上かつ出来高2倍以上、またはストップ高）し、熱量が平常時より上がった | 監視に入れる。買うならごく小さく |
| **初動** | 急騰が3銘柄以上に広がり、熱量55以上。平常時は静か（35未満）で、まだ大きく上がっていない（20日で市場より+35%未満） | 2番手候補を中心に検討。損切りの目安は −8% かテーマの失速 |
| 加速 | 初動の後、テーマ全体が出来高を伴って一斉に上がった（熱量80以上、急騰が3日で3銘柄以上増えた） | 保有は続ける。新規は出遅れの2番手候補だけ |
| 過熱 | 20日で市場より+35%以上、またはストップ高が連発 | 新規の買いは控える。一部の利益確定を検討 |
| 失速 | 初動から5日以上たち、熱量が直近10日の最高の半分を下回った | 手仕舞いを検討 |

**熱量（0〜100）**は、テーマの銘柄のうち「3%以上上がった割合」「出来高が2倍以上になった割合」「20日の高値を更新した割合」「急騰した銘柄の数」「市場（TOPIX）より何%多く上がったか」をまとめた数字です。

候補銘柄は2種類に分けます。
- **先導株**：もう大きく上がった銘柄（5日で+15%以上、ストップ高など）。追いかけると高値づかみになりやすい
- **2番手候補**：まだ大きく上がっていないが、出来高が増え始めた銘柄（直近3日の出来高が平均の1.5倍以上、売買代金が十分ある）

合成データでのテストでは、2026年9月下旬〜10月のサイバー株に似た動き（1銘柄のストップ高 → 2銘柄の急騰 → 10/6の一斉高）に対して、**1銘柄だけのときは何も出さず、急騰が3銘柄に広がった日（一斉高の前）に「初動」**を出しました。

## 設置手順（最初の1回だけ・約10分）

1. Googleドライブで新しいスプレッドシートを作り、名前を **「テーマ株レーダー」** にする（Claude はこの名前で探します）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身をすべて消し、[`dist/Code.gs`](dist/Code.gs) の中身を貼り付けて保存（Ctrl+S）
4. 左の歯車（プロジェクトの設定）→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック → エディタに戻り、`appsscript.json` の中身を [`dist/appsscript.json`](dist/appsscript.json) に置き換えて保存
5. 上の関数の選択欄で `setup` を選んで **実行**
   - 「承認が必要です」と出たら、権限を確認 → 自分のアカウント →「このアプリは Google で確認されていません」と出たら **詳細 → （安全ではないページ）に移動** → 許可
   - 自分で作ったスクリプトなので、この警告は問題ありません。使う権限は、スプレッドシートの読み書き、株価の取得（外部への接続）、自動実行、メール送信（「GASからもメールする」を「はい」にしたときだけ使う）です
6. スプレッドシートに戻って再読み込みすると、メニューに **「テーマ株レーダー」** が出る → **今すぐ更新** を押す（1分ほど）
7. **「テーマ」シートの「状態」列**を確認し、「取得できません」の行はコードを直すか消す（上場廃止やコード変更があります）
8. メニューの **バックテスト（過去2年）** を押し、「バックテスト」シートで成績を確認する（下の「確かめ方」）

この後は、平日の夕方に自動で動きます。何もしなくてかまいません。

## シートの見方

| シート | 内容 |
|---|---|
| 通知用 | 今日の結論（Claude が最初に読む）。状態・対象の取引日・アラート |
| シグナル | 全テーマの段階・熱量・各指標。動いているテーマが上に来る |
| 候補銘柄 | 動いているテーマの先導株と2番手候補 |
| アラート | これまでのシグナルの記録（取引日ごと） |
| 履歴 | 毎日の全テーマの段階と熱量 |
| テーマ | 監視するテーマと銘柄。**自由に追加・削除してよい**（1テーマ3銘柄以上。コードは 4493 や 153A の形） |
| 設定 | しきい値など。初動の熱量を上げると通知が減り、確度が上がる |
| バックテスト／バックテスト明細 | 過去2年のシグナルの成績 |

## 確かめ方（バックテスト）

「バックテスト」シートは、過去2年に出たシグナルごとに、**翌日の始値で買って5・10・20日後の終値で評価したとき、市場（TOPIX）より何%上がったか**の平均と勝率を出します。
一番下の「比較：毎日テーマを買った場合」より成績がよいシグナルだけを信じるのが基本です。
数字を Claude に見せてもらえれば、しきい値の調整やテーマの入れ替えを一緒に行います。

## 限界と注意

- **必ず上がる銘柄は分かりません。** 出すのは「上がる確率が普段より高い局面」の候補です。投資判断はご自身で行ってください
- 株価は Yahoo! Finance（米国版）から無料で取得しています。仕様の変更や混雑で取れない日があり、その日は「通知用」にエラーが出ます
- 監視するのは「テーマ」シートにある銘柄だけです。リストにない新しいテーマは、Claude が毎日のストップ高一覧などから探して「新テーマ候補」として知らせます
- ストップ高で寄り付かない日は、実際には買えません。バックテストはこれを考えていないので、先導株の成績は実際より良く見えます
- 銘柄のリストは2026年10月時点で作りました。上場廃止・コード変更（例：QPS研究所 5595 → QPSホールディングス 464A）があるので、「テーマ」シートの状態列をときどき確認してください
