# 株モメンタム・アラート

テーマ（サイバーセキュリティ、AI半導体、原子力、防衛 など）や個別銘柄が **「上がり始めた段階」** で知らせるツールです。
毎朝7:30（日本時間・平日）に GitHub Actions で自動実行し、新しいシグナルがあればメール／Discord に届きます。費用はかかりません。

## 何を見ているか

| 見るもの | 中身 |
|---|---|
| 指数より強いか | 10日・5日の上昇率から S&P500（日本株は TOPIX）の上昇率を引いたもの |
| 出来高 | 直近5日の出来高がその前50日の何倍か（資金が入り始めたか） |
| 高値の上抜け | 前日までの55日高値を終値で超えたか |
| 移動平均 | 終値 > 20日線 > 50日線、20日線が上向き |
| 溜め | 上抜け前の値幅が狭かったか（狭い横ばいからの上抜けほど強い） |
| **テーマの広がり** | 同じテーマで何割の銘柄が同時に動いているか、テーマETFが高値を更新したか |
| **ニュースの急増** | Googleニュースで、テーマの記事数が普段の何倍か（新聞社・テレビ局・ネットメディアのWeb記事を含む） |

これらから 0〜100点の点数をつけ、段階を判定します。

- **初動**：点数が高く、まだ20日で+15%以内・50日線から+12%以内（一番知りたい段階）
- **加速**：点数は高いが、すでにある程度上がっている
- **過熱**：20日で+30%超、50日線から+25%超など。追いかけ買いに注意

テーマのアラートは「テーマ内の4割以上の銘柄が同時に動いている」ときに出ます。今回のサイバーセキュリティのような**セクター全体の資金流入**を、個別銘柄のノイズより早く・確かにとらえるためです。
ニュースだけが急増して株価がまだ動いていないテーマは「話題が先行」として別に知らせます。株価とニュースが同時に動いたテーマには **★話題も急増** がつきます。

同じ銘柄・同じ段階は10日間は再通知しません（段階が上がったときは通知します）。

## 設置手順（最初の1回）

1. GitHub のこのリポジトリで **Settings → Secrets and variables → Actions → New repository secret** から通知先を登録（どちらか片方でよい）
   - メール（Gmail）：`SMTP_USER`（送信に使う Gmail アドレス）、`SMTP_PASS`（Googleアカウントで発行した **アプリパスワード**）、`ALERT_TO`（届け先。カンマ区切りで複数可）
   - Discord：`DISCORD_WEBHOOK_URL`（チャンネル設定 → 連携サービス → ウェブフック で作成。スマホに通知が来るので一番手軽）
2. **Actions** タブ → 「株モメンタム・アラート」→ **Run workflow** で `dry-run` を選んで実行し、結果（Summary）が出ることを確認
3. 同じく `backtest` を実行し、過去3年で「初動」シグナルが出た後の成績を確認（下記）
4. 以後は平日の朝に自動で動きます

※ スケジュール実行は GitHub の既定ブランチ（main）にあるときだけ動きます。

## 監視対象を変える

`config.yaml` を編集します。テーマを足す・銘柄を入れ替える・ニュースの検索語を変える・判定のしきい値を変える、はすべてここです。
日本株は `7011.T` のように「コード.T」で書きます。

## 手元で動かす

```
pip install -r requirements.txt
python -m momentum_alert.main --dry-run     # 通知せず結果を表示
python -m momentum_alert.backtest           # 過去検証
python -m pytest tests                      # テスト
```

## 限界（必ず読んでください）

- **未来を当てる道具ではありません。** 「上がり始めた」ことを早く知らせるだけで、そのまま失速することも多くあります（だましの上抜け）。損切りの位置を決めずに入らないでください。
- **バックテストで中身を確かめてから使ってください。** `backtest` は、初動シグナル後の20日間の超過リターンと、30日以内に急騰（20日+30%）に至った割合を、全営業日の平均と比べます。全営業日と差がなければ、しきい値を見直す必要があります。
- バックテストは**今の監視リストで過去を見る**ので、結果的に上がったテーマを選んでいる分だけ良く出ます（生存者バイアス）。
- テレビの放送内容は直接は見ていません（無料で機械的に取れる手段がないため）。テレビ局のWeb記事は Googleニュース経由で含まれます。
- Googleニュースの検索結果は最大100件なので、記事がとても多い話題では件数の伸びが小さく出ます。数回動かすと過去の件数を記録し、それを普段の水準として使います。
- 株価は Yahoo Finance（yfinance）から取得しています。仕様変更で一時的に取れなくなることがあります。
