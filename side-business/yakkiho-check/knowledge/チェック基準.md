# 広告表現チェック基準（知識ベース）

AIの一次チェックと、薬剤師による最終確認の両方で使う基準。
**条文・通知の原文で定期的に確認すること**（最終確認日を末尾に記録）。ここに書いていない論点が出たら、調べて追記する。

---

## 0. まず「何の広告か」を決める（ここを誤ると全部ずれる）

| 区分 | 根拠 | 言える効能の範囲 |
|---|---|---|
| 医薬品 | 承認書 | 承認された効能効果の範囲内のみ |
| 医薬部外品（薬用化粧品など） | 承認書 | 承認された効能効果。＋化粧品の効能（56項目）も併記可 |
| 化粧品 | 「化粧品の効能の範囲」通知（平成23年 薬食発0721第1号） | **56項目の範囲内のみ**（メーキャップ効果・使用感は別） |
| 医療機器 | 承認・認証・届出 | 承認等の範囲内 |
| 機能性表示食品 | 消費者庁への届出 | **届出した表示の範囲内のみ** |
| 特定保健用食品（トクホ） | 消費者庁の許可 | 許可された表示の範囲内 |
| 栄養機能食品 | 食品表示基準 | 定められた栄養成分の機能表示のみ |
| 一般の健康食品・サプリ | ― | **効能効果は一切言えない**（言うと無承認医薬品とみなされる） |
| 美容機器・雑貨 | ― | 身体の構造・機能への作用を言うと医療機器とみなされる恐れ |

> 依頼時に「区分」と「承認書・届出の内容」を必ず受け取る。分からないまま判断しない。

## 1. 薬機法（医薬品医療機器等法）

### 1-1. 条文の骨組み
- **第66条 誇大広告等の禁止**：効能・効果・性能について、虚偽・誇大な記事を広告してはならない。医師などが保証したと誤解させる記事も同じ。
- **第67条 特定疾病用の医薬品の広告制限**：がん・肉腫・白血病など、一般の人向けの広告が制限される。
- **第68条 承認前の医薬品等の広告禁止**：承認を受けていないもの（健康食品を含む）について、医薬品的な名称・効能を広告してはならない。
- **措置命令**（第72条の5）：2025年11月に虚偽・誇大広告で初めて適用された。
- **課徴金**（2021年8月施行）：違反期間の対象商品の売上の4.5%。

### 1-2. 医薬品等適正広告基準（平成29年9月改正）の主な論点
化粧品・医薬部外品・医療機器にも適用される（解説通知が対象を明記）。

| 論点 | NGになりやすい例 | 考え方 |
|---|---|---|
| 効能効果の範囲の逸脱 | 化粧品で「シミが消える」「シワを改善」「アンチエイジング」 | 化粧品は56項目の範囲内。範囲外は言い換えても不可 |
| 効能効果の保証 | 「必ず効く」「効果を保証」「100%実感」 | 効果の保証は不可 |
| 安全性の保証 | 「副作用なし」「安全」「肌に優しいから誰でも安心」 | 安全性を保証する表現は不可 |
| 最大級の表現 | 「最高」「最強」「No.1」「日本一」「世界初」 | 最大級表現は原則不可（客観的な事実でも慎重に） |
| 効き目の速さ・程度 | 「即効」「すぐに」「1回で」「劇的」 | 発現の程度を誇大に言うのは不可 |
| 本来の効能でない作用 | 化粧品で「痩せる」「デトックス」「血行促進」 | 化粧品として認められない効能 |
| 医薬関係者等の推薦 | 「医師が推薦」「薬剤師おすすめ」「皮膚科医も愛用」 | **医薬関係者・病院などが推薦・選用している旨の広告は不可**（※当サービスの薬剤師名も、依頼主の広告に「推薦」として出してはいけない） |
| 使用前後の比較 | ビフォーアフター写真・図 | 効能効果の保証と受け取られる恐れがあるため原則不可 |
| 体験談 | 「3日でニキビが治りました（個人の感想です）」 | 効能効果の保証になる体験談は不可。注記を付けても違反は消えない |
| 他社の誹謗 | 「他社の化粧水は効かない」 | 不可 |
| 不安をあおる | 「放っておくと大変なことに」 | 不快・不安・恐怖を与える表現は不可 |
| 疾病の名前 | 「アトピーに」「ニキビが治る」「花粉症対策」 | 化粧品・健康食品で疾病の治療・予防を想起させるのは不可 |

### 1-3. 化粧品の効能の範囲（56項目）

2. 香りにより毛髪、頭皮の不快臭を抑える。
3. 頭皮、毛髪をすこやかに保つ。
4. 毛髪にはり、こしを与える。
5. 頭皮、毛髪にうるおいを与える。
6. 頭皮、毛髪のうるおいを保つ。
7. 毛髪をしなやかにする。
8. クシどおりをよくする。

22. 肌荒れを防ぐ。

24. 皮膚にうるおいを与える。
25. 皮膚の水分、油分を補い保つ。
26. 皮膚の柔軟性を保つ。

28. 皮膚の乾燥を防ぐ。

**その他**
56. 乾燥による小ジワを目立たなくする。（日本香粧品学会「化粧品機能評価法ガイドライン」に基づく試験等で効果を確認した場合に限る）

**よくある範囲外の言葉（化粧品）**：治る、治療、改善、再生、修復、若返り、アンチエイジング、エイジングケア（※「年齢に応じたお手入れ」の意味と明記した場合は可と整理されることが多い）、シミが消える・薄くなる、美白（※医薬部外品で承認がある場合を除く）、発毛・育毛（※医薬部外品の承認範囲を除く）、デトックス、浸透（※「角質層まで」と範囲を明記すれば可とされることが多い）、肌の奥深く、細胞、ターンオーバーを促す。

### 1-4. 健康食品（一般食品）の判断：46通知（昭和46年 薬発第476号）
医薬品に当たるかは次の4要素を**総合的に**判断する。
1. **成分本質（原材料）**：「専ら医薬品として使用される成分本質」に当たるか（食薬区分の例示で確認）
2. **形状**：アンプル形状など医薬品と誤認させる形状か（錠剤・カプセルは直ちにNGではない）
3. **効能効果の表示**：疾病の治療・予防、身体の機能の増強・増進をうたっているか
4. **用法用量の表示**：「1日3回、食後に」など医薬品的な服用時期・量の指定

NG例：「血圧を下げる」「血糖値が気になる方の治療に」「免疫力アップ」「代謝を高めて脂肪燃焼」「疲労回復」「便秘解消」「関節の痛みに」「がん予防」
→ 一般の健康食品はこれらを言えない。言いたいなら機能性表示食品・トクホの制度を使う必要がある。

### 1-5. 機能性表示食品
- 言えるのは**届出した表示の範囲内**のみ。届出にない機能、届出より強い表現（「改善する」など）は不可。
- 2024年の紅麹問題を受けて制度が見直された（健康被害の報告義務、GMPなど）。**最新の運用を消費者庁の資料で必ず確認**する。

## 2. 景品表示法

| 論点 | 内容 | 典型的な問題 |
|---|---|---|
| 優良誤認（第5条1号） | 実際より著しく優れていると示す | 根拠のない「業界最高水準」。消費者庁は「不実証広告規制」で、15日以内に合理的な根拠の提出を求められる |
| 有利誤認（第5条2号） | 価格・取引条件を実際より有利に見せる | 「今だけ半額」が常態化、二重価格の比較対照価格に根拠がない |
| 打消し表示 | 強い表示と小さな注記の矛盾 | 「誰でも痩せる」＋小さく「効果には個人差があります」→ 注記で違反は消えない |
| No.1表示 | 根拠となる調査の妥当性 | イメージ調査だけでの「満足度No.1」は問題視されている |
| **ステマ規制**（令和5年内閣府告示第19号、2023年10月1日施行） | 事業者の広告なのに、広告と分からない | インフルエンサー投稿に「広告」「PR」等の表示がない。**責任を負うのは広告主（事業者）** |

- **課徴金**：対象商品の売上の3%。
- ステマの判断ポイント：事業者が**表示内容の決定に関与**したか（具体的な指示、対価の提供、継続的な関係など）。

## 3. 健康増進法（第65条）
食品として販売するものについて、健康の保持増進の効果等について、著しく事実に相違する表示や、著しく人を誤認させる表示をしてはならない。景表法と同時に問題になることが多い。

## 4. 判定の3段階（納品レポートで使う）

| 判定 | 意味 | 依頼者への返し方 |
|---|---|---|
| **NG** | 条文・基準に明確に反する | 削除または言い換え案を必ず付ける |
| **要注意** | 文脈・根拠・表示次第でNGになりうる | 何があればOKになるか（根拠資料、注記の位置、範囲の明記など）を書く |
| **要確認** | 事実関係が分からないと判断できない | 依頼者に確認すべき事項を質問の形で書く（承認書の内容、届出番号、調査の方法など） |

## 5. このサービスの線引き（毎回守る）
- 提供するのは**広告表現の校正と助言**。法的な紛争、行政対応、法律上の見解書は扱わず、弁護士を紹介する。
- 最終的な掲載の判断は依頼者が行う（契約書に明記）。
- 当サービスの薬剤師名を、依頼主の広告に「推薦者」「監修者」として出さない（医薬関係者の推薦に当たる恐れ）。記事の監修は別契約で、表現を個別に確認する。
- 迷ったら厳しい側に倒す。「たぶん大丈夫」は書かない。
