# テーマレーダー（試作品）

「サイバーセキュリティ」「防衛」「半導体」などの**テーマ株に資金が入り始めたことを、動き始めて0〜2営業日のうちに知らせる**ツールです。
Googleスプレッドシートに約20テーマ・約110銘柄を登録しておき、毎日夕方に株価とニュース件数を自動で調べ、合図が出た日だけメールで知らせます。費用はかかりません。

- プログラム：`gas/` フォルダ（編集用）、`dist/` フォルダ（貼り付け用。`tools/build.js` で生成）

## 何ができて、何ができないか

- **できること**：同じテーマの複数の銘柄が「市場平均より強く上がる」「出来高が増える」「高値を更新する」をそろって起こした日に、「初動」として知らせる。その手前の小さな変化（熱量の急上昇・株価より先に出来高が増える・関連ニュースの急増）も「予兆」として知らせる
- **早さの目安**：ニュースや SNS で話題になってから気づくのに比べて、**数日〜1週間ほど早く**気づけることを狙っている。値上がりを先回りして当てる道具ではない
- **できないこと**：登録していないテーマは見つけられない。新しいテーマ（例：株探の「人気テーマ」ランキングで見かけたもの）は、自分で「テーマ銘柄」シートに足す
- 合図は「調べ始めるきっかけ」。買う・売るの判断は、材料（ニュース・決算）と地合いを確かめてから

## 合図の種類

| 状態 | 意味 | メール |
|---|---|---|
| 初動 | 直前2週間は静かだったテーマで、複数の銘柄がそろって出来高を伴って上がり始めた | 送る |
| 予兆 | その手前。熱量が5日で急に上がった／株価はまだだが出来高が増えている／関連ニュースが普段の2.5倍以上 | 送る |
| 上昇中 | 勢いが続いている | 送らない |
| 過熱 | 25日移動平均からテーマ平均で20%以上離れた。高値づかみに注意 | 送る |
| 失速 | 勢いが落ちた | 送らない |

**熱量**（0〜100）は、次の4つを点数にした合計です。平常時はおおむね10〜45、60以上で「動いている」とみなします。

- 強さ（35点）：5日間で市場平均よりどれだけ強かったか。値動きの大きい銘柄ほど割り引く
- 出来高（25点）：普段（60営業日平均）の何倍か。暴落の日のように全銘柄の出来高が増える日は割り引く
- 高値更新（25点）：直近3日に20日高値を付けた銘柄の割合
- 広がり（15点）：市場平均より強い銘柄の割合

強さと出来高はテーマの上位半数の平均を使うので、一部の銘柄が先に動く「初動」を拾えます。1銘柄だけの急騰では上がりきらないので、その会社だけの材料はテーマの合図になりにくくなっています。

## 設置手順（最初の1回だけ・約10分）

貼り付けるのは **`dist/` フォルダの2ファイル**だけです。

1. Googleドライブで新しいスプレッドシートを作る（名前は「テーマレーダー」など）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身をすべて消し、`dist/Code.gs` の中身を貼り付けて保存（Ctrl+S）
4. 左の歯車（プロジェクトの設定）→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック → エディタに戻り `appsscript.json` の中身を `dist/appsscript.json` に置き換えて保存
5. 上の関数の選択欄で `setup` を選んで **実行**
   - 初回は「承認が必要です」と出る → 権限を確認 → 自分のアカウントを選ぶ →「このアプリは Google で確認されていません」と出たら **詳細 → （安全ではないページ）に移動** → 許可
   - 株価とニュースを取りに行く「外部サービスへの接続」、通知の「メール送信」、毎日の「自動実行」の許可を求められます
6. スプレッドシートに戻って**再読み込み**すると、メニューに **「テーマレーダー」** が出る
7. **テーマレーダー → 今すぐ更新**（1〜2分）。「ダッシュボード」に今日の一覧が出る
8. **テーマレーダー → 過去の合図を検証（2年分）**。「検証」シートで、過去に合図が出たあとテーマが市場を上回ったかを確かめる（下の「最初に確かめること」）
9. **テーマレーダー → 毎日の自動更新をオンにする**。平日の18時ごろに自動で更新し、合図が出た日だけメールが届く
10. **テーマレーダー → 通知メールを試しに送る** で、メールが届くことを確かめる

プログラムを更新したときは、`dist/Code.gs` を貼り直して保存するだけです（シートのデータは消えません）。

## 最初に確かめること（大事）

合図の決め方は、架空の相場でしか試せていません（開発環境から株価サイトにつなげなかったため）。実際の相場で役に立つかは、**設置したら最初に「検証」シートで確かめてください。**

- 「初動」「予兆」の「その後10日」が「参考：全期間の平均」より良ければ、合図に意味があったと言えます
- 一覧で、**2026年10月上旬のサイバーセキュリティ**に合図が出ていたかを見てください（10/6 にサイバーセキュリティクラウド・カウリスがストップ高）
- はずれが多すぎるときは「設定」で「初動の熱量」を上げる（65〜70）、少なすぎて遅いときは下げる（55）
- 注意：銘柄リストは今の目線で選んでいるので、あとから人気になったテーマほど成績が良く見えやすい

## 毎日の使い方

1. メールが来たら「ダッシュボード」を開く。上から 初動 → 予兆 → 上昇中 → 過熱 の順に並ぶ
2. 気になるテーマの「よく動いた銘柄」と「ひとこと」を見て、何の材料で動いているかをニュースで確かめる
3. 「銘柄の動き」シートで、テーマの中の個別の銘柄を見る。合図の列の意味：
   - **急騰**：5日間で、いつもの値動きの2.5倍以上、市場より強かった
   - **出来高急増**：当日の出来高が普段の2倍以上
   - **出来高先行**：株価はまだ動いていないのに出来高が増えている（先回りの買いのことがある）
   - **テーマ内で未上昇（出来高は増加）**：テーマは動いているが、この銘柄はまだ上がっていない。出遅れか、上がらない理由があるかを確かめる
4. 「熱量の推移」シートで、テーマの熱量の60営業日分の推移を見られる

日中に「今すぐ更新」を押すと、その日の途中の値で計算します（メールは送りません）。

## テーマ・銘柄の変え方

| シート | 内容 |
|---|---|
| テーマ銘柄 | テーマ名・証券コード・銘柄名。日本株は4桁のコード（`4493`、`153A`）、米国株はティッカー（`CRWD`）。テーマ欄が空なら上の行と同じテーマ。1テーマ4銘柄以上がおすすめ（3銘柄未満は判定しない） |
| ニュース語 | テーマごとのGoogleニュースの検索語（`不正アクセス OR 情報漏えい` のように OR でつなぐ）。直近24時間の記事数を数え、14日分たまると普段との比を出す。毎日100件に張り付く語は広すぎるので絞る |
| 設定 | 通知先メール、通知する状態、ベンチマーク、合図の基準、自動更新の時刻 |

初期の銘柄リストは、2026年10月時点の代表的な銘柄を入れた出発点です。コードの誤りや上場廃止に気づいたら直してください（取得できなかった銘柄はダッシュボードの下に赤字で出ます）。

## 限界と注意

- 株価は **Yahoo Finance の非公式な取得口** から取っています。仕様変更や混雑で取れなくなることがあります。ほとんど取れなかった日は「取得できませんでした」とメールが届きます（黙って何も来ない、にはしていません）
- 東証の終値が反映されるのは夕方です。自動更新は18時ごろにしてあります
- 小型株中心のテーマは、TOPIX（1306）と比べると相場全体の小型株高でも強く見えます。気になるときは「設定」のベンチマークを `2516.T`（グロース250連動ETF）にする
- このツールは投資助言ではありません。合図が出ても、上がり続けるとは限りません
