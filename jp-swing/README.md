# jp-swing：日本株スイングトレード（2週間〜半年）の銘柄選定・発注指示ツール

毎日の終値データから「翌営業日に出す注文」を作ります。あなたは指示書どおりに証券会社で発注するだけです。
売買ルールは過去データで検証（バックテスト）でき、発注ツールとバックテストは**同じルール**で動きます。

> **最初に読んでください**
> - 年20%は「狙う目標」であり、このツールが保証するものではありません。TOPIXの長期平均は年7〜8%程度で、
>   年20%を何年も続けられるプロは少数です。**実データでのバックテスト結果を見てから**、目標と資金を決めてください。
> - 大事なのは勝率より**期待値（勝率×平均利益 − 負け率×平均損失）**です。勝率70%でも、1回の大負けで利益は消えます。
>   このツールは「勝率は5割前後、ただし負けを小さく・勝ちを大きく」を基本にしています。
> - 投資判断の最終責任はご自身にあります。

## 仕組み（何を見て買うか）

| 観点 | 使うデータ | ルール |
|---|---|---|
| 市場全体の流れ | TOPIX | TOPIXが200日線の上かつ50日線>200日線なら通常どおり、200日線の上だけなら保有枠を半分、下なら新規買いなし |
| 機関投資家の動き（市場全体） | 投資部門別売買状況（海外投資家） | 直近4週の海外投資家の現物売買が売り越しなら、保有枠を一段階減らす |
| 機関投資家の動き（銘柄） | 出来高 | 過去50日で、上昇した日の出来高が下落した日より多い（継続的な買い集め）。20日平均売買代金5億円以上に限定 |
| 業績・財務 | 決算短信 | ROE（会社予想）、営業利益の前年同期比、**業績予想の上方修正**、予想に対する進捗率、自己資本比率、営業CFを点数化し、55点以上。赤字予想・予想PER40倍超は除外 |
| 相対的な強さ | 株価 | 過去6か月（直近1か月を除く）でTOPIXに勝っている |
| 買うタイミング | 株価 | 上昇トレンド中（終値>50日線>200日線、200日線が上向き、52週高値から15%以内）の**押し目**（RSI 38〜58、5日前より安い） |
| 決算の日 | 決算発表日 | 発表の7営業日前からは新規買いをしない（決算1日で大きく下がる事故を避ける） |

候補は「相対的な強さ40%＋財務35%＋買い集め25%」で順位付けし、上位から買います。

**損失の管理（ここが一番大事）**
- 1回の損切りで失うのは資金の**1%**まで。株数はこれに合わせて自動計算（1銘柄の上限は資金の20%）
- 買ったら即、逆指値（買値 − ATR×2）を入れる
- 含み益が損切り幅（1R）に達したら、逆指値を買値まで引き上げる
- 以後は「保有中の最高値 − ATR×3」まで逆指値を引き上げ続ける（利益を伸ばしつつ守る）
- 終値が50日線を割る、または保有120営業日（約半年）で手仕舞い
- 同時保有は最大8銘柄、同じ業種は2銘柄まで

## 準備（最初の1回）

1. Python 3.10以上を入れ、このフォルダで `pip install -r requirements.txt`
2. [J-Quants](https://jpx-jquants.com/)（JPX公式のデータサービス）に登録
   - **無料プランはデータが12週間遅れるため、発注には使えません**（バックテストには使えます）
   - 毎日の発注には Light プラン以上が必要です。財務データと投資部門別売買状況が使えるプランか、プラン表で確認してください
3. 認証情報を環境変数に設定
   ```
   export JQUANTS_EMAIL=登録したメールアドレス
   export JQUANTS_PASSWORD=パスワード
   ```
4. 動作確認：`python -m jpswing demo`（架空データで動くか確かめるだけ。数字に意味はありません）
5. データ取得：`python -m jpswing fetch --start 2016-01-01`（初回は数時間かかります。2回目以降は差分だけ取得）

> J-Quants の API の仕様が変わっていて取得に失敗する場合は、`jpswing/data.py` の冒頭に書いた形式でデータを
> `data/` に置けば、残りの処理はそのまま動きます。

## 手順1：まず検証する（実際のお金を入れる前に必ず）

```
python -m jpswing backtest --start 2018-01-01 --capital 3000000
```

表示される項目の見方：

| 項目 | 見るポイント |
|---|---|
| 年率リターン／TOPIX年率 | TOPIXに勝っているか。20%に届くか |
| 最大ドローダウン | 資産がピークから最大何%減ったか。**この下落に耐えられる金額しか入れない** |
| 勝率・損益比 | 勝率×損益比のバランス。損益比1.5以上が目安 |
| 1回あたり期待値(R) | プラスであること（0.2R以上が目安） |
| 年別 | 特定の年だけで稼いでいないか。2020年（コロナ）、2022年、2024年8月の急落でどうだったか |

**過剰最適化に注意**：`jpswing/config.py` の数値をいじって過去の成績を良くするのは簡単ですが、それは将来の成績になりません。
変更するなら「2018〜2022年で調整 → 2023年以降で確認」のように、調整に使っていない期間で成績が落ちないことを確かめてください。

```
python -m jpswing backtest --start 2018-01-01 --end 2022-12-31   # 調整用
python -m jpswing backtest --start 2023-01-01                    # 確認用（ここは見るだけ）
```

## 手順2：毎営業日の運用（所要10分）

夕方（J-Quants のデータ更新後）に：

```
python -m jpswing fetch --start 2016-01-01
python -m jpswing orders --equity 口座の評価額 --cash 買付余力
```

`output/orders_YYYYMMDD.md` に指示書ができます。翌朝、寄付き前に：

1. **売り**：書かれた銘柄を寄付き成行で売る → 売れたら `positions.csv` からその行を削除
2. **逆指値**：保有株の逆指値を、書かれた価格に変更する（ツールが `positions.csv` の stop を更新済み）
3. **新規買い**：書かれた指値・株数で注文（当日限り）。約定したら**同日中に逆指値を入れ**、指示書の最後にある行を
   実際の約定値に直して `positions.csv` に追記

`positions.csv` の形式（最初は空で構いません。ファイルがなければ保有なしとして扱います）：
```
code,entry_date,entry_price,shares,stop,risk,highest
```

## 段階的な始め方（おすすめ）

1. 実データでバックテストし、結果が納得できるか確認（1〜2週間）
2. 1〜2か月は、指示書どおりに**紙の上で**売買を記録（実際の約定とのずれを確認）
3. 使う予定の資金の3分の1で開始。3か月、成績がバックテストから大きく外れなければ増やす

## このツールの限界

- 信用取引の残高、空売り比率、大量保有報告書は現在使っていません（追加候補）
- 決算の中身（一過性の利益か等）や、ニュース・不祥事は判断できません
- 業種の偏りは「同じ業種2銘柄まで」だけで管理しています。相場全体の急落（2024年8月のような）では同時に下がります
- 株価の呼値は通常銘柄の表で丸めています。TOPIX100構成銘柄など細かい呼値の銘柄では、少し不利な値になることがあります

## ファイル構成

| ファイル | 内容 |
|---|---|
| `jpswing/config.py` | すべての数値ルール |
| `jpswing/data.py` | J-Quants からの取得・保存 |
| `jpswing/features.py` | テクニカル・財務・市場環境の指標（先読みしないよう、決算は開示の翌営業日から使う） |
| `jpswing/strategy.py` | 銘柄選定・株数計算 |
| `jpswing/backtest.py` | 過去検証・損切りルール |
| `jpswing/orders.py` | 発注指示書 |
| `tests/` | `python -m pytest` で実行 |
