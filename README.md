# シフト作成ツール（試作品）

薬局5店舗・約30人の月間シフトを、希望をもとに自動で下書きし、画面上で調整するツールです。
Googleスプレッドシートにデータを保存し、GAS（Google Apps Script）の画面をURLで開いて使います。費用はかかりません。

- 仕様：[docs/SPEC.md](docs/SPEC.md)
- プログラム：`gas/` フォルダ

## 使い方の流れ（毎月）

1. **① 希望入力**：紙で集めた希望（休み・有給・×・※・重信など）を、記号を選んでセルを押して入力する
2. **自動作成**：ボタンを押すと、ルールに沿って1か月分の下書きができる
3. **② シフト**：右側の「確認が必要なこと」を見ながら、記号を選んでセルを押して調整する
4. **保存** → **印刷用シート**：印刷用の表がスプレッドシートに作られる

希望入力で入れた枠は、自動作成で変更されません（茶色の枠で表示されます）。

## 設置手順（最初の1回だけ・約15分）

1. ツール専用のGmailアカウントでGoogleドライブを開き、新しいスプレッドシートを作る（名前は「シフト作成」など）
2. メニューの **拡張機能 → Apps Script** を開く
3. 左の「ファイル」に、`gas/` フォルダの次のファイルを同じ名前で作り、中身を貼り付ける
   | 作る種類 | ファイル名 |
   |---|---|
   | スクリプト | `Code`（最初からある `コード.gs` の中身を置き換える） |
   | HTML | `Index`、`Styles`、`Body`、`Logic`、`SampleData`、`App` |
4. 歯車（プロジェクトの設定）→「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック → `appsscript.json` の中身を貼り付ける
5. 関数 `setup` を選んで **実行**（初回は権限の確認が出るので許可する）。スプレッドシートにシートがまとめて作られる
6. **「社員」シート**に社員を登録する（書き方は `gas/社員シートの記入例.csv` を参照）
7. Apps Script の右上 **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
8. 表示されたURLをブックマークする。このURLは、このGoogleアカウントでログインしているときだけ開けます

プログラムを更新したときは、**デプロイ → デプロイを管理 → 編集 → バージョン：新バージョン** で反映します。

## マスタ（スプレッドシートで直接編集）

| シート | 内容 |
|---|---|
| 店舗 | 記号と店舗名 |
| 必要人数 | 店舗・曜日区分（平日/土曜/当番）・午前/午後ごとの最低人数 |
| 社員 | 職種、区分、所属店舗、固定配置、応援できる店舗、夜勤可など |
| 祝日・休業日 | 休業する日（祝日のほか、年末年始の休業日もここに追加） |
| 臨時営業 | 門前の病院に合わせて臨時で開ける日 |
| 夜間当番日 | 三番町の夜間当番日（初期値は2026/8/1から8日ごと） |
| 特別期間 / 特別期間の必要人数 | お盆・年末年始・GWなど。人数が足りなくても黄色の注意表示にとどめる |

## 手元で試す（開発用）

```sh
node test/logic.test.js                 # 自動作成とルール判定のテスト
node test/build-preview.js preview.html # 仮名サンプルで動くデモ画面を1ファイルに書き出す
```
