# シフト作成ツール 仕様書（ドラフト v0.1）

薬局5店舗・約30人（社員・アルバイト）の月間シフトを、希望をもとに自動で下書きし、管理者が画面で調整して確定するためのツール。

> 社員の氏名など個人情報はこのリポジトリに置かない。実データはスプレッドシート（マスタ）側で管理する。

---

## 1. 全体方針

| 項目 | 決定内容 |
|---|---|
| 構成 | Googleスプレッドシート（データ保存）＋ GAS Webアプリ（URLで開く操作画面） |
| 利用者 | 管理者1名のみ。GASの公開範囲を「自分のみ」にして制限する |
| アカウント | 個人Gmail（推奨：ツール専用のGmailアカウントを新しく作る） |
| 希望の収集 | 当面は紙で集め、管理者が入力画面で入力する。将来はGoogleフォームへの移行を検討 |
| 自動化の範囲 | 自動作成は「下書き」。人数不足やルール違反を表示し、最終判断は管理者が行う |

### 2.1 営業日
- 平日：午前・午後
- 土曜：午前のみ（午後は休み）
- 日曜・祝日：休み
- **臨時営業**：門前の病院に合わせて、店舗・日付ごとに臨時で営業日を追加できる

### 2.2 必要人数

| 店舗 | 平日 午前 | 平日 午後 | 土曜 午前 |
|---|---|---|---|
| 三番町 | 薬剤師3・事務2 | 薬剤師2・事務2 | 薬剤師2・事務1 |
| 一番町 | 薬剤師1・事務1 | 薬剤師1・事務1 | 薬剤師1・事務1 |
| 中一万 | 薬剤師2・事務1 | 薬剤師2・事務1 | 薬剤師2・事務1 |
| 山越 | 薬剤師1・事務1 ※事務は要確認 | 薬剤師1・事務1 | 薬剤師2・事務1 |
| 松山 | 薬剤師2・事務2 | 薬剤師2・事務2 | 薬剤師2・事務2 |

- 上の数字を**最低人数**とする。下回った枠は赤で警告する
- 事務は一番町・三番町で構造的に週1日ほど足りなくなる。実際に足りないまま回しているため、自動では埋めず警告の表示だけにする
- 将来、**理想人数**（届かない枠は黄色で表示）も設定できるようにする
- 数字は店舗設定の画面から変更できる

### 2.3 特別期間（お盆・年末年始・ゴールデンウィークなど）
- 通常より休みが多くなる期間を、名前・開始日・終了日で登録する（年ごとに登録）
- 特別期間中は、店舗・時間帯ごとに**期間専用の必要人数**を設定できる（未設定なら通常の人数を使う）
- 期間中は休みの希望が集中するので、人数が足りない枠は**黄色の注意表示**にとどめ、管理者が画面で調整して決める

## 3. 社員

### 3.1 属性（スプレッドシートのマスタで管理）
- 職種：管理薬剤師 ／ 薬剤師 ／ 助手・事務
- 区分：常勤 ／ 準常勤 ／ 非常勤
- 所属店舗（メイン）
- 出勤できる店舗（複数・優先順位つき）＝店舗を移動する人
- **固定配置**：必ず特定の店舗に出勤する（管理薬剤師5人は全員、それぞれの店舗に固定）
- 夜勤ができるか（準夜勤・深夜勤）
- 勤務パターンの制限（例：平日16:15まで、土曜13:00まで）
- 出勤できない曜日（アルバイトの固定の休み）
- 外部アルバイトかどうか（夜勤のみの人など）
- 週あたりの店舗出勤日数の上限・在宅勤務の日数（例：週1回在宅、店舗出勤は週4日）

## 4. 夜間当番（三番町）

- 当番日は8日ごと（例：2026年8月は1、9、17、25日）。管理者が月ごとに入力・修正できる
- 当番日に必要な枠：
  - **準夜勤 16:00〜24:00**：当番日の夕方
  - **深夜勤 0:00〜9:00**：当番日の翌日の0時から
- 夜勤に配置できるのは「夜勤可」の薬剤師と、外部のアルバイトだけ
- 事務は夜勤の対象外

| 勤務 | 翌日 |
|---|---|
| 準夜勤 16-24 | 通常どおり出勤してよい |
| 深夜勤 0-9 | **必ず休み** |

- 深夜勤は当番日の翌日の0時から。その日の日中勤務は入れない（「明」と表示）。翌々日は通常どおり出勤できる
- 深夜勤の人は、前日（当番日）は**午前 9-13 のみ**勤務できる。午後は勤務なし（「入」と表示）
- 半日勤務も1日の勤務として数える
- 当番日が日曜・祝日のときは三番町の日中（午前・午後）、土曜のときは三番町の午後にも薬剤師1人を配置する（2026/8/9・8/1の実績より）
- 準夜勤と深夜勤は別の人にする

---

## 5. 勤務の区分と記号

1日を午前・午後の2段で表示する（今の紙のシフト表と同じ形）。時間の指定が必要な勤務は、勤務パターンとして登録する。

| 記号・表記 | 意味 | 薬剤師の人数に数えるか |
|---|---|---|
| 店舗の記号（一・三・中・山・松） | その店舗に出勤 | 数える |
| ※ | 出勤扱いだが店舗にいない | **数えない** |
| 重信 | 店舗にいない（出勤日には数える） | **数えない** |
| 在宅 | 在宅勤務（出勤日には数える） | 事務の人数に**数えない** |
| 16-24 ／ 0:00-9:00 など | 夜勤・時間指定の勤務 | 夜勤の枠として数える |
| 16:15 ／ 13:00 など | その時間まで勤務 | 数える |
| 定休 | 週のもう1日の休み | — |
| 有給 ／ お盆 | 休暇 | — |
| × | 出勤できない（非常勤） | — |

## 6. ルール

### 6.1 必ず守るルール（違反すると自動作成では配置しない／手で変えたときは赤で警告）
1. 希望休は守る
2. 営業していない日・時間帯には配置しない
3. 固定配置の人は所属店舗にだけ配置する
4. 連勤は6日まで
5. 週2日は必ず公休。平日に祝日がある週は、祝日と日曜で2日とし、それ以外の日は出勤
   - 有給・特休（お盆など）は公休2日とは**別に追加で**取る（公休の数に含めない）
6. 深夜勤0-9の翌日は休み
7. 夜勤には夜勤可の人だけを配置する
8. アルバイトの出勤できない曜日には配置しない
9. 非常勤は、社員ごとに設定した週の出勤上限日数を超えない（未設定なら週3日。半日も1日と数える）

### 6.2 できれば守るルール（優先度順）
1. 必要人数（最低人数）を満たす
2. 所属店舗を優先し、足りない店舗には「出勤できる店舗」に登録された人を回す
3. 店舗間の移動や夜勤の回数を、人によって偏らせない

## 7. 画面と機能（予定）

1. **マスタ設定**：店舗、必要人数、社員、勤務パターン、祝日、臨時営業日、夜間当番日
2. **希望入力**：紙の希望を1人分ずつ素早く入力する画面
3. **自動作成**：ボタン一つで1か月分の下書きを作る
4. **調整画面**：今の紙の表と同じレイアウトで表示。セルを直すとその場で人数とルールを判定し、不足や違反に色を付ける
5. **出力**：印刷用のシート（PDF）

## 9. 試作品で置いた仮の判断（要確認）

- 深夜勤の日は出勤日として数える（連勤の計算）
- 非常勤は、常勤で足りない枠を埋める役として配置する（週の出勤上限まで。上限は画面で氏名を押して変更できる）。「出」を希望入力すると、その日は優先して入れる
- 月をまたぐ週は、月内の日数だけで休みの数を判定する（前月・翌月の分は見ない）

## 10. 進め方

1. 本仕様書で内容を合意する
2. GAS＋スプレッドシートで試作品を作る ← 今ここ（`gas/`）
3. 2026年8月の希望を入力し、自動作成の結果を紙の表と比べる
4. 1か月分を手作業のシフトと並行して運用し、比べる
5. 本番に切り替える
