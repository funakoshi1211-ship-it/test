# シフト作成ツール 仕様書（ドラフト v0.1）

薬局5店舗・約30人（社員・アルバイト）の月間シフトを、希望をもとに自動で下書きし、管理者が画面で調整して確定するためのツール。

> 社員の氏名など個人情報はこのリポジトリに置かない。実データはスプレッドシート（マスタ）側で管理する。

---

## 1. 全体方針

| 項目 | 決定内容 |
|---|---|
| 構成 | Googleスプレッドシート（データ保存）＋ GAS Webアプリ（URLで開く操作画面） |
| 利用者 | 管理者1名のみ。GASの公開範囲を「自分のみ」にして制限する |
| アカウント | 個人Gmail（推奨：ツール専用のGmailアカウントを新しく作る） |
| 希望の収集 | 当面は紙で集め、管理者が入力画面で入力する。将来はGoogleフォームへの移行を検討 |
| 自動化の範囲 | 自動作成は「下書き」。人数不足やルール違反を表示し、最終判断は管理者が行う |

## 3. 社員

### 3.1 属性（スプレッドシートのマスタで管理）
- 職種：管理薬剤師 ／ 薬剤師 ／ 助手・事務
- 区分：常勤 ／ 準常勤 ／ 非常勤
- 所属店舗（メイン）
- 出勤できる店舗（複数・優先順位つき）＝店舗を移動する人
- **固定配置**：必ず特定の店舗に出勤する（管理薬剤師5人は全員、それぞれの店舗に固定）
- 夜勤ができるか（準夜勤・深夜勤）
- 勤務パターンの制限（例：平日16:15まで、土曜13:00まで）
- 出勤できない曜日（アルバイトの固定の休み）
- 外部アルバイトかどうか（夜勤のみの人など）

### 3.2 固定配置の扱い
- 自動作成では、固定配置の人を所属店舗以外に配置しない
- 管理者が手で別の店舗に変更した場合は、警告を出したうえで受け付ける

---

## 4. 夜間当番（三番町）

- 当番日は8日ごと（例：2026年8月は1、9、17、25日）。管理者が月ごとに入力・修正できる
- 当番日に必要な枠：
  - **準夜勤 16:00〜24:00**：当番日の夕方
  - **深夜勤 0:00〜9:00**：当番日の翌日の0時から
- 夜勤に配置できるのは「夜勤可」の薬剤師と、外部のアルバイトだけ
- 事務は夜勤の対象外

| 勤務 | 翌日 |
|---|---|
| 準夜勤 16-24 | 通常どおり出勤してよい |
| 深夜勤 0-9 | **必ず休み** |

---

## 5. 勤務の区分と記号

1日を午前・午後の2段で表示する（今の紙のシフト表と同じ形）。時間の指定が必要な勤務は、勤務パターンとして登録する。

| 記号・表記 | 意味 | 薬剤師の人数に数えるか |
|---|---|---|
| 店舗の記号（一・三・中・山・松） | その店舗に出勤 | 数える |
| ※ | 出勤扱いだが店舗にいない | **数えない** |
| 重信 | 店舗にいない | **数えない**（出勤日に数えるかは要確認） |
| 16-24 ／ 0:00-9:00 など | 夜勤・時間指定の勤務 | 夜勤の枠として数える |
| 16:15 ／ 13:00 など | その時間まで勤務 | 数える |
| 定休 | 週のもう1日の休み | — |
| 有給 ／ お盆 | 休暇 | — |
| × | 出勤できない（非常勤） | — |

## 6. ルール

### 6.1 必ず守るルール（違反すると自動作成では配置しない／手で変えたときは赤で警告）
1. 希望休は守る
2. 営業していない日・時間帯には配置しない
3. 固定配置の人は所属店舗にだけ配置する
4. 連勤は6日まで
5. 週2日は必ず休み。平日に祝日がある週は、祝日と日曜で2日とし、それ以外の日は出勤
6. 深夜勤0-9の翌日は休み
7. 夜勤には夜勤可の人だけを配置する
8. アルバイトの出勤できない曜日には配置しない

### 6.2 できれば守るルール（優先度順）
1. 必要人数（最低人数）を満たす
2. 所属店舗を優先し、足りない店舗には「出勤できる店舗」に登録された人を回す
3. 店舗間の移動や夜勤の回数を、人によって偏らせない

## 7. 画面と機能（予定）

1. **マスタ設定**：店舗、必要人数、社員、勤務パターン、祝日、臨時営業日、夜間当番日
2. **希望入力**：紙の希望を1人分ずつ素早く入力する画面
3. **自動作成**：ボタン一つで1か月分の下書きを作る
4. **調整画面**：今の紙の表と同じレイアウトで表示。セルを直すとその場で人数とルールを判定し、不足や違反に色を付ける
5. **出力**：印刷用のシート（PDF）
